# CY80RG — Beyond Human Limits

A responsive cyborg-themed landing page built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies — just clean, modern frontend code.

## Live Demo

[View Live Page](https://yourusername.github.io/your-repo-name)

## Features

- Glitch animation on hero title
- Animated stats counter on scroll
- Rotating neural core visual with terminal
- Scroll-reveal timeline section
- Fully responsive down to mobile
- Scanline CRT overlay effect
- Pure HTML/CSS/JS — zero dependencies

## Tech Stack

- HTML5
- CSS3 (custom properties, clip-path, animations, grid)
- Vanilla JavaScript (IntersectionObserver, setInterval)
- Google Fonts (Orbitron, Share Tech Mono, Inter)
